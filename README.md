### Selected work.

**[starbucks-order-whisperer](https://github.com/hansonyjy/starbucks-order-whisperer)**
1st place of 19 teams at the UCLA Starbucks Data Challenge. A 3-stage NLP pipeline that turns free-text drink requests into ranked recommendations. Claude extracts the constraints, rules filter the menu, and a hybrid scorer ranks what is left.

**[churn-roi](https://github.com/hansonyjy/churn-roi)**
A calibrated churn model inside an expected-value engine. Given a fixed retention budget, it picks which customers are worth saving and the return to expect. Not just who is likely to leave.

**[global-macro-dashboard](https://github.com/hansonyjy/global-macro-dashboard)**
Tracks growth, inflation, policy, and liquidity across 8 economies. Scores each against its own history, places it in a cycle regime (Goldilocks, Reflation, Stagflation, Disinflation), and translates that into sector and factor reads. Built-in data health checks flag stale or conflicting sources, and scenario paths are labeled as scenarios, not forecasts.
